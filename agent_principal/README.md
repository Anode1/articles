# The Agent as a Principal

**A coding agent on a releaser's machine holds the release permission and acts on text the releaser did not write; the rule gives it an identity of its own wherever its developer can release, and then the agent reaches production only as a committer without release rights does, through a person's release.**

Short theoretical paper, 10 pages. Definitions, three assumptions and three claims with arguments, one figure, no project material: the chain before agents and its invariant; what the agent changes; where the chain breaks (Claim 1, releasers' machines only, with a table of checks and whether a program can supply them); the rule as four clauses with the recipe, the restoration claims and the corollary; one hypothetical team before and after; relation to OWASP LLM06, the lethal trifecta, the Rule of Two; a clause table with the check for each.
