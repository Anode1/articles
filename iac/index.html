Abstract

Multi-agent coordination on one machine is treated as a messaging problem and handed to a queue, a broker, or an inter-agent protocol. That answers the wrong question. Moving bytes between processes was solved decades ago. The hard part is that an LLM agent, between turns, is not a running process at all: slow, serial, dormant, so the throughput a broker manages never binds. The scarce primitive is a wakeup, and the only one a stateless agent can receive is the return of a blocking recv parked in a cheap child process the harness re-invokes on exit: one activation per message, not per poll. The move is the epoll_wait every network server blocks in, relocated from the agent, which cannot hold it, to a child process, which can. We present iac, a dependency-free C99 board of about 1,100 lines, one binary, no heap. The economy is measured: a self-polling agent reprocesses its whole context on every check, millions of tokens an hour to watch an empty mailbox, while a C-blocked wakeup costs zero on any model. The transport is an append-only text log under a file lock, the commit log a log-based broker is built on minus the service, auditable by cat and grep and, because every agent reads the whole shared log, open to peer review. On one host a message is a file append and a page-cache read, and the same proximity keeps the shared history cheap to re-read. The participant is new: an agent woken by nothing but a returning process. A fleet of agents used the board to build the board; three seats later carried an external repair to a verified result.
