# Electricity for data centres, priced rather than rationed

**Provinces should sell electricity to data centres at a published price instead of handing
out permissions, and should sell a cheaper kind that can be switched off a few dozen hours a
year.**

Plugging a large data centre into a Canadian grid today means applying for permission, not
buying power. BC holds a contest. Alberta set a cap and it is already full. Quebec wants to
double the price. Ontario passed a law letting a minister decide, and has not written the
rules. When a monopoly has more buyers than supply it either names a price or picks winners,
and all four picked winners.
